# 리프맵 LeafMap — 부산 채식 메뉴 성분 확인 웹 대시보드

AI데이터기반서비스기획 중간과제 · 2023761031 이다운

부산을 찾는 외국인 채식 여행자가 **식당 이름이 아니라 메뉴의 재료·육수·양념 제품 성분 근거**를 보고 메뉴를 고를 수 있도록 돕는 서비스의 MVP 웹 시제품입니다. 기획서의 모바일 앱 구상을 설치 없이 링크로 여는 **웹 대시보드**로 바꿨습니다.

## 화면 구성
| 메뉴 | 내용 |
|---|---|
| 대시보드 개요 | AI 추천 운영 업무, 핵심 지표, 식단별 메뉴 판정, 지역별 확보율, 데이터 신선도(90일), 활동 기록 |
| 등록·검토 큐 | ‘추가 확인 필요’ 메뉴 처리, 식당 확인 요청 문장, 신규 등록 폼과 누락 항목 점검 |
| AI 성분 분석 | 성분표 원문(한/영)을 동물 유래 재료 사전과 대조해 식단별 판정 초안 생성 → 운영자 검토 |
| 정정 제보·문의 | 접수→검토 중→반영/기각 흐름, 여행자·사장님용 한국어 요청 문장 생성 |
| 메뉴 탐색 (여행자 뷰) | 식단·제외 재료 설정, 지역 선택, 지도·목록, 메뉴 상세와 성분 근거, 한국어 카드, 정정 제보 (한/영 전환) |
| 고객 검증 계획 | 핵심 가설, 측정 기준(사전 목표), 인터뷰 질문, 4주 일정 |
| 시장·경쟁 분석 | 부산 방문 외국인 추이, 경쟁 서비스 비교, 포지셔닝 맵 |
| 수익 모델·확장 | 수익원 가설, 수익 시뮬레이터, 확장 로드맵 |
| 기획 개요·참고자료 | 대상·불편·해결, 웹 전환 이유, 이전 기획서 대비 개선점, 출처 |

## 판정 규칙
- **제외 재료 포함**: 사용자의 제외 재료 중 하나라도 사용한 것으로 확인
- **추가 확인 필요**: 제품 불명, 식당 사용 확인 대기, 상충 제보
- **조건에 맞음**: 제외 재료를 대조할 근거가 있고 식당 사용 확인 완료

## 실행
빌드 없이 `index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하세요.

## 유의 사항
식당·메뉴·제품·제보·운영 기록은 모두 시연용 가상 데이터입니다. 목표 수치·일정·수익 금액은 검증 전 가설입니다. 버튼으로 바꾼 상태는 브라우저 localStorage에만 저장되며, 사이드바의 ‘데모 데이터 초기화’로 되돌릴 수 있습니다.
